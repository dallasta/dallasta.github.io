# Luca Dall'Asta — Academic Pages publication records

This folder contains a cleaned set of publication records prepared for the Academic Pages `_publications/` collection.

The records were assembled from the current Politecnico di Torino staff profile, the PoliTO IRIS author catalogue, and cross-checks against public bibliographic/arXiv sources.

The current PoliTO IRIS author view reports 72 catalogue records. Some catalogue entries correspond to non-journal outputs or metadata variants, so this package is intentionally a **cleaned publication list**, rather than a blind one-to-one dump of every IRIS item. The current English PoliTO staff profile also lists the 2026 paper *Enzyme-Driven Phase Separation*, which is included.

Important:
- DOIs are included only when they were explicitly verified in the retrieved public metadata.
- No DOI has been invented for records where the available source did not expose one.
- Some older records have deliberately generic venue labels where the retrieved IRIS snippet did not provide enough bibliographic detail.
- Before publishing the final site, I recommend one final bibliographic pass to decide whether chapters/conference items should be separated from journal articles and to add arXiv links/abstracts where useful.

All files are ready to copy into `_publications/`.
