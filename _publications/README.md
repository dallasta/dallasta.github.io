# Publications

Add one Markdown file per publication.

Example front matter:

```yaml
---
title: "Title of the paper"
authors: "L. Dall'Asta, A. Author, B. Author"
collection: publications
date: 2026-01-01
venue: "Physical Review Letters"
paperurl: "https://doi.org/..."
arxiv: "https://arxiv.org/..."
doi: "https://doi.org/..."
---
```

Do not enter placeholder bibliographic information: replace it with verified records.
